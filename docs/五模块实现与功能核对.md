## 演示路径

1. 空数据库时，在监测中心点击“初始化公开数据演示”。建立三个明确标注的示例档案；不将公开案例混入已有用户档案。
2. 装备管理选择“多旋翼动力诊断演示”，查看动力、能源、导航、通信和执行机构；仅动力绑定公开飞行案例及已有模型。
3. 健康分析运行装备分析，查看局部诊断、时间趋势和来源。未接入部件为“未评估”；覆盖率不是健康分。
4. 监测中心复核异常，生成维修工单；维修管理依次处理、提交复检并关闭。重复点击建单不会为同一告警重复创建活动工单。
5. 健康分析选择独立“电池寿命试验台”，默认只使用截至第 60 次循环的观测，展示容量、SOH、RUL 和经验区间。
6. 模型中心查看训练/验证/测试指标与版本比较，或从现有原始数据发起新训练。

## 数据与状态约束

- TII 案例是飞行任务，不是已经接入的真实飞机。NASA 电池与 TII 飞机没有装机关系；不得将二者合成为同一实机证据。公开案例仅可绑定“演示档案”。
- 用户 CSV 保留设备/任务来源，但其物理归属与适用工况仍需使用者确认。当前只适配六轴惯性信号，用户电池 CSV 尚未接入。
- 结构、绑定或模型启停变更后，旧分析标为过期。停用模型不再执行新推理，历史分析保留。
- 历史分析保存装备结构、绑定、模型及输入指纹；不会因新训练而重写。重复分析复用同一事件身份，保留复核意见与关闭状态。新数据任务或不同模型版本是不同事件来源。
- 整机健康分和失效概率尚未标定，保持未知。动力 HI 是示意指标，分类概率未经校准。电池区间是探索性经验误差区间，不是寿命保证。
- 分类故障窗口至少 3 个且占比 ≥10% 时会建议人工复核；电池预测 RUL ≤20 次循环会建议容量复检。这是可追溯的演示维护规则，不是经现场验证的工程阈值。
- 自动分析不宣称维修有效。关闭工单必须填写复检结果，可选择同装备分析作为辅助证据，也允许人工复检记录。
- 旧窗口/事件台账保留在维修管理子页面；与新增装备告警台账分开，不推测历史事件所属实机。

## 保存与验证

- 业务状态：`runs/platform.sqlite`；分析快照与趋势：`runs/analyses/<分析编号>/`。
- 旧事件：`runs/events.sqlite`；训练实验、导入文件保持既有位置。
- 本地 SQLite 与同步推理适合初始演示。尚无多用户权限、并发任务队列、生产服务治理或在线协议适配。
- 自动测试覆盖五模块页面、原回放/训练/版本比较入口、层级归属、公开数据绑定限制、未知状态、版本停用、分析过期、告警去重、复核保留、工单状态约束及实际界面闭环。测试使用隔离数据库，不改写用户复核台账。

实测结果：38 项自动测试全部通过（含 18 个子菜单页面切换与刷新定位、伺服真实模型和业务闭环）；独立 Chrome 检查五个主页面均无异常，1440 px 桌面与 390 px 窄屏完成布局检查，窄屏无页面级横向溢出。

## 下一阶段优先级

1. 接入一种实际设备数据链路（MAVLink 或 ROS 2/CAN），实现设备身份、在线数据质量、增量推理与断流降级。
2. 扩展伺服同步指令/反馈数据及真实 UGV 日志，验证跟踪性能、跨负载和跨设备诊断。当前伺服支持公开无负载台架振动分类，见 [伺服诊断数据与验证说明](伺服诊断数据与验证说明.md)。
3. 有实机证据后，开展分系统健康标定和任务风险评估；再扩展轴承/减速器寿命模型。

这些是后续工程范围，未通过空页面、模拟指标或演示按钮冒充完成。
